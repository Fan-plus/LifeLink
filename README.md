# LifeLink
## 记忆与健康守护智能体

> 暂时设想是主要是针对老年人，后续如果有其他方向变更 再改变


## 功能概览
<details>
<summary>点击展开查看详细功能</summary>

- **多模态记忆和理解辅助**：包括药盒、银行卡等。设定记忆库，可动态添加针对记忆的物品。每次语音询问的时候动态更新，AI更新的方式可以通过 **智能识别背景** 或者 **语音识别**。 可以对老人不理解的语言和知识比如药盒说明书等进行解释和多语种翻译。
- **跨设备联动**：利用OPPO手表检测**跌倒或者心率异常**。检测到异常时，手机端自动报警，并给子女发送信息提醒。
- **亲属检测**：子女可以实时查看老人的健康状况，防患于未然。
- **情感陪伴**：利用AIGC生成“**虚拟孙辈**”形象或者声音，进行日常提醒和聊天
- **签到打卡**：可以选择开启签到打卡功能，缺少打卡自动打电话给子女。  签到方式可以利用**OPPO手表的心率监测**，如果连续长时间没有数据来源，开启震动加最大闹钟。向预设联系人发送包含：当前 GPS 定位、最后时刻的心率数据、环境录音（判断是否在呼救）的求救短信/邮件。
- **AI回忆录和遗嘱保险箱**

## 技术分析

项目采用 **“端云结合 + 硬件协同”** 的架构，通过本地大模型（On-device LLM）与多模态感知技术，构建了一个低延迟、高隐私的适老化智能助手。

### 1. 核心技术栈
*   **端侧大模型 (On-device LLM)**：集成 `llama.cpp` 原生库与 JNI 桥接层，在安卓端本地部署 **Qwen-GGUF** 轻量化模型。通过 `libomp` 多核加速，实现无网环境下的意图识别、文本纠错与情感对话。
*   **深度学习推理 (Edge AI)**：采用 **Google LiteRT (原 TFLite)** 引擎，运行自研的 `intent_classifier.tflite`（意图分类）与 `sentinel_guard.tflite`（防诈判别）模型，实现毫秒级预判。
*   **计算机视觉 (CV)**：基于 `Google ML Kit` 实现药盒说明书、银行卡等文字的高精度 OCR 识别；结合 `CameraX` 实现流畅的取景与自动对焦。
*   **语音交互 (Voice UI)**：融合系统级 `Speech-to-Text` 与 `TTS` 技术，构建“全语音”交互闭环，降低老年人点击屏幕的认知负担。

### 2. 各模块技术实现逻辑

#### A. 首页：语音交互中枢 (Dual-Engine Pipeline)
*   **账号与云端同步**：基于腾讯云实现用户鉴权，通过生成的唯一“邀请码”与微信公众号对接，实现家属端的零成本绑定与异常推送。
*   **混合意图判别流水线**：
    1.  **一级过滤**：`intent_classifier.tflite` 对语音文本进行快速分类。
    2.  **逻辑路由**：
        *   若判定为 `AI_CHAT`：路由至云端大模型 API，获取丰富的情感价值与生活百科回复。
        *   若判定为 `REMINDER`：调用本地 LLM 运行 **Schema 提取 Prompt**，解析出结构化 JSON（如 `{"time":"10m", "event":"吃药"}`），并自动注册 `AlarmManager` 系统闹钟，到点通过语音强提醒。
        *   若判定为 `物品查询`：通过本地QWEN找到主语 再到数据库%模糊查询

#### B. 记忆守护：OCR 增强与语义化 (OCR + NLP)
*   **信息提取**：通过 LLM 将一句话提取出要点，比如说药盒在桌子上，提取出药盒，桌子，加入记忆库。
*   **识别修复**：利用 `ML Kit` 提取药盒原始文本，再交由本地 LLM 进行语义补全与纠错（纠正因拍摄模糊或光线问题导致的错别字）。
*   **信息精简**：通过 LLM 将冗长的说明书精简为“用法、用量、禁忌”三要素，并转化为口语化播报。

#### C. 健康预警：多源传感器融合 (Sensor Fusion)
*   **跨设备联动**：通过 `WearOS Data Layer API` 实时同步手表端的加速度传感器与心率计原始数据。
*   **跌倒判别算法**：在手机端运行二阶段校验（加速度峰值检测 + 姿态角突变分析 + 心率骤变关联），发送短信和发送到绑定的微信公众号。

#### D. 时光珍藏：生成式回忆录 (Creative AI)
*   **长文本合成**：调用 `LlamaManager` 的 `generateMemoir` 接口，将离散的日常语音记录、图像文本碎片串联并润色为文学化的回忆录。
*   **隐私保险箱**：遗嘱与敏感信息采用 **AES-256 对称加密**，解密密钥托管于安卓系统级 `KeyStore`，确保数据不出本地。

#### E. 反诈中心：多维风险研判 (Anti-fraud Pipeline)
*   **三层防御体系**：
    1.  **关键词匹配**：针对转账、安全账户等敏感词进行瞬时过滤。
    2.  **本地研判**：利用 `sentinel_guard.tflite` 对通话摘要进行离线风险分级。
    3.  **云端深度分析**：针对高危行为异步请求云端大模型进行逻辑推理，通过悬浮窗动态展示预警等级。

### 3. 性能优化方案
*   **原生算力挖掘**：通过 `CMake` 配置 `C++` 优化编译选项，利用 ARM 架构的 `NEON` 指令集加速矩阵运算。
*   **异步调度策略**：LLM 推理与模型加载均在独立的 `Background Thread` 执行，确保 UI 线程在语音采集过程中保持 60fps 响应。

## 预计页面
<details>
<summary>点击展开查看预计页面详情</summary>

1. 首页（默认页，健康总览）
布局：顶部标题 + 3 个核心健康卡片 + 超大 AI 语音速查模块 + 6 宫格快捷功能入口
核心：健康状态一眼看全 + 语音速查所有信息 +设置提醒+ 一键跳转其他功能，高频操作全覆盖
2. 记忆守护（核心优化页）
布局：顶部标题 + 记忆库卡片（手动添加物品） + 【一键拍照识别 + AI 语音播报 + 3D 视频讲解】核心区
核心：无文本框，纯拍照识别药品，语音读说明 + 3D 视频演示用药
3. 健康监测
布局：顶部标题 + 3 个健康数据卡片（心率 / 睡眠 / 跌倒检测） + 异常预警列表 + 一键紧急呼救按钮
核心：纯数据展示，手表联动实时监测，预警全开，遇险点红色呼救按钮即可
4. 亲属互联
布局：顶部标题 + 亲属列表卡片 + 签到打卡预警模块
核心：绑定子女共享健康数据，打卡防失联，超时自动给子女发提醒，仅 1 个「手动打卡」按钮
5. 暖心陪伴
布局：顶部标题 + 虚拟孙辈陪伴模块 + 语音交互区
核心：纯情感陪伴，语音聊天、讲故事、吃药提醒，无文字操作，一键语音互动
6. 时光珍藏
布局：顶部标题 + AI 回忆录模块 + 遗嘱保险箱模块
核心：一键生成文字 / 语音回忆录，加密存储遗嘱，隐私保护，仅「生成 / 编辑 / 查看」3 个简单按钮
7. 诈骗风险检测
布局：暖心陪伴页面的控制开关+悬浮窗
核心：通过本地（自训练TFLITE模型）+云端大模型（qwen)综合研判确定是否存在风险再手机震动和提醒
</details>
