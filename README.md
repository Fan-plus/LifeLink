# LifeLink
## 记忆与健康守护智能体

> 暂时设想是主要是针对老年人，后续如果有其他方向变更 再改变


## 功能概览
<details>
<summary>点击展开查看详细功能</summary>

- **多模态记忆和理解辅助**：包括药盒、银行卡等。设定记忆库，可动态添加针对记忆的物品。每次语音询问的时候动态更新，AI更新的方式可以通过 **智能识别背景** 或者 **语音识别**。 可以对老人不理解的语言和知识比如药盒说明书等进行解释和多语种翻译。
- **跨设备联动**：利用OPPO手表检测**跌倒或者心率异常**。检测到异常时，手机端自动报警，并给子女发送信息提醒。
- **亲属检测**：子女可以实时查看老人的健康状况，防患于未然。
- **情感陪伴**：利用AIGC生成“**虚拟孙辈**”形象或者声音，进行日常提醒和聊天
- **签到打卡**：可以选择开启签到打卡功能，缺少打卡自动打电话给子女。  签到方式可以利用**OPPO手表的心率监测**，如果连续长时间没有数据来源，开启震动加最大闹钟。向预设联系人发送包含：当前 GPS 定位、最后时刻的心率数据、环境录音（判断是否在呼救）的求救短信/邮件。
- **AI回忆录和遗嘱保险箱**

</details>


## 技术分析

融合了OCR（药盒识别）、NLP（语音交互）、传感器数据分析（手表跌倒检测）



## 设计理念

尽可能方便老人操作，只需佩戴手表，手机作为被动计算中心

## 预计页面
<details>
<summary>点击展开查看预计页面详情</summary>

1. 首页（默认页，健康总览）
布局：顶部标题 + 3 个核心健康卡片 + 超大 AI 语音速查模块 + 6 宫格快捷功能入口
核心：健康状态一眼看全 + 语音速查所有信息 + 一键跳转其他功能，高频操作全覆盖
2. 记忆守护（核心优化页）
布局：顶部标题 + 记忆库卡片（手动添加物品） + 【一键拍照识别 + AI 语音播报 + 3D 视频讲解】核心区
核心：无文本框，纯拍照识别药品，语音读说明 + 3D 视频演示用药
3. 健康监测
布局：顶部标题 + 3 个健康数据卡片（心率 / 睡眠 / 跌倒检测） + 异常预警列表 + 一键紧急呼救按钮
核心：纯数据展示，手表联动实时监测，预警全开，遇险点红色呼救按钮即可
4. 亲属互联
布局：顶部标题 + 亲属列表卡片 + 签到打卡预警模块
核心：绑定子女共享健康数据，打卡防失联，超时自动给子女发提醒，仅 1 个「手动打卡」按钮
5. 暖心陪伴
布局：顶部标题 + 虚拟孙辈陪伴模块 + 语音交互区
核心：纯情感陪伴，语音聊天、讲故事、吃药提醒，无文字操作，一键语音互动
6. 时光珍藏
布局：顶部标题 + AI 回忆录模块 + 遗嘱保险箱模块
核心：一键生成文字 / 语音回忆录，加密存储遗嘱，隐私保护，仅「生成 / 编辑 / 查看」3 个简单按钮

</details>

## 目前实现页面
<details>
<summary>点击展开查看已实现页面详情</summary>

### 首页面
1. 页面标题区
位于页面顶部，包含应用Logo和欢迎标题，使用简洁的文字和图标组合，提供清晰的页面标识。
2. 核心健康卡片区（左右滑动）
使用HorizontalScrollView实现的可横向滑动卡片区域，包含三个健康相关卡片：
- 健康总览卡片 ：显示步数、睡眠等健康数据，使用绿色状态指示器和清晰的数据展示
- 记忆库卡片 ：提供快捷查看重要信息（如用药提醒、物品位置）的功能
- 签到状态卡片 ：显示今日签到情况和连续签到天数
每个卡片采用白色背景、圆角设计和阴影效果，尺寸统一为200dp×280dp，间距合理，支持横向滑动浏览。
3. AI语音速查模块（已优化）
采用蓝色虚线边框的卡片式设计，是首页的视觉焦点区域：
- 标题区域包含麦克风图标和"AI语音速查 · 问啥都知道"的醒目标题
- 功能说明文字清晰描述语音助手的功能：找东西、查药品、记事项等
- 大型语音按钮采用圆角设计，包含麦克风图标和引导文字，支持按住说话交互
- 底部文字列出支持的提问类型
整体设计现代美观，视觉层次分明，交互提示清晰。
4. 快捷功能入口区（6宫格布局）
采用两行三列的网格布局，提供6个核心功能的快速访问入口：
- 健康数据
- 用药提醒
- 紧急求助
- 生活助手
- 健康知识
- 个人中心
每个功能入口包含圆形图标和文字说明，使用卡片式设计和点击涟漪效果，布局均匀，间距适中，便于快速识别和操作。
5.整体特点
- 布局结构 ：采用垂直流式布局，各模块之间有明确的视觉分隔和合理的间距
- 颜色方案 ：以白色为主背景，搭配蓝色（eye_friendly_accent）作为主题色，绿色表示健康状态，红色用于紧急功能
- 交互体验 ：包含卡片滑动、按钮点击涟漪效果等交互反馈
- 响应式设计 ：适配不同屏幕尺寸，保证在各种设备上都有良好的显示效果
首页整体设计符合老年人使用习惯，字体清晰、按钮大、功能分区明确，同时具有现代的视觉美感。

</details>
